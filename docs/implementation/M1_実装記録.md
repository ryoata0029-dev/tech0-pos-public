## 変更と理由

- `backend/app/services/pricing.py`：不変の商品行条件、最大候補1件、数値ID同額順、候補額と実値引きの区別、税率別の合算後切捨て、円額上限拒否。計算完了まで結果を返さず入力を変更しない。
- `backend/app/services/validation.py`：コードの全体一致、真偽値や数値文字列を数量として受けない検証、円額／率の無丸め解析、内部ID範囲、UTC変換と半開期間。
- `backend/tests/test_pricing.py`・`test_validation.py`：承認済み例と失敗境界を独立した期待値で検査。
- `backend/README.md`：実行コマンド、責務、未実装範囲を記載。

仕様変更・新規依存なし。今回作成済みのプロジェクト計画と文書マップの既存未コミット差分は保持。戻す場合は今回の`backend/`と本実装記録、計画への状態追記だけを対象にし、以後の変更がないことを確認して差分を戻す。DBの戻し操作は不要。
