# 商品を残したままの選択解除

2026-10-04。本人がiPhone試験中に選択解除のため商品を削除していたと報告し、選択解除を依頼した。対象は[F13〜F15](../requirements/機能・非機能要件.md#r-topic-27)・[数量の受入条件](../requirements/受入条件_現行.md#r-topic-27)、[画面設計3.2](../design/画面と業務処理.md#sec-3-2)・[TC-02](../tests/テストケース.md#tc-02)。選択解除の追加に関する本人指示を[履歴](../../設計承認履歴.md)へ記録した。

選択商品欄に「選択解除」を追加。選択・未送信数量だけをクリアし、商品・登録済み数量・金額・会員・検索表示・カメラを保持する。通常の編集制限を適用し、APIは送信しない。再選択すると登録済み数量を表示する。

変更は `frontend/app/register-cart.tsx` と、実コンポーネントの回帰 `frontend/tests/register-selection.test.mjs`、行ボタンの表示文字列も照合する `frontend/tests/support/register-harness.mjs`。本番依存の追加なし。別担当の読取レビューで確実な追加欠陥なし。回帰1件は選択→未送信数量→解除で商品・数量・金額・API未送信・カメラ設定保持、再選択、編集不可を確認する。実DOM・実撮影の代替ではない。

`make check`成功：Python71＋Node99＝170件、lint・型・OpenAPI22操作。[全検査ログ](evidence/mac-batch/check-selection-fix.log)。`make build`成功：[buildログ](evidence/mac-batch/build-selection-fix.log)、build `JgJjC7D_Z2jjtELoFKU-V`。[版・source hash・独立レビュー](evidence/mac-batch/runtime-selection-fix.json)。

Mac専用環境 `tech0-pos-mac-batch-mysql` の修正前はカート0・売上0。DBを保持してアプリのみ停止し、修正版を起動。Chromeの通常ログイン・初回開始・Cookie確認・初回カートを経て、商品0001／0002を各1個登録した。数量8を未送信で入力→選択解除で選択表示と編集欄のみ消え、同商品を再選択すると登録済み数量1へ戻り、別商品も選択できた。商品0003の検索結果・会員未指定の表示も保持。[解除前後と再選択のDOM・DB比較](evidence/mac-batch/comparison-selection-fix.json)ではカートv4・2行・税抜210円・税18円・税込228円・売上0、register／contexts／cart／lines／operations／purchases／purchase_lines／purchase_taxes／productsの9集合が完全一致。別担当もソース・設計・ログ・DOM・画像・DB比較を独立確認した。

[ボタン表示](evidence/mac-batch/ui-selection-button.png)・[解除後の画面](evidence/mac-batch/ui-selection-after.png)。検索待ち中の選択解除無効と待ち終了後の再有効も限定観測したが、[追加検索試験](evidence/mac-batch/comparison-tc02-old-replies.json)では旧応答のChrome受信分類と10秒以内の画面復帰は未確認。[集計・CUA追加試行の限界](evidence/mac-batch/verification-attempts.json)を残し、通常選択解除の成功と区別する。

Macの実カメラは開いていない。iPhoneでの新しい選択解除操作と実映像継続は未実施。先行の[iPhone限定結果](iPhone_カメラ試験_結果.md)では数量上限後に削除・カメラ再開始を挟んだため、再開始なしの次商品受付は未実施のまま。TC-02全体・M5・M7の受入合格を意味しない。

[最終DB](evidence/mac-batch/db-final-selection-fix.json)も同じカートv4・2行・228円・売上0を保持。[終了確認](evidence/mac-batch/shutdown-final-selection-fix.json)で今回のトンネル・アプリ・DB停止、3307／8443／8444閉鎖、container exited、専用volume保持、秘密値のGit候補・ログ不在を確認した。
