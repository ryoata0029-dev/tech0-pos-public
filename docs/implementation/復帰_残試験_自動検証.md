## 証拠の限界と残範囲

storageはメモリ上の偽物に故障を注入し、実ハンドラが送信を止めることを確認した。Chromeの設定・OS・実localStorageの容量／権限障害、実Cookie、画面描画、終了・再起動の挙動は確認していない。

Home試験では子RegisterCartをprops境界で観測している。再認証後に渡すcartの同一性とenableの制御を確認したもので、6状態すべての子画面の操作制限を描画確認したものではない。保存中で結果照合できない場合の子画面停止は、別の実RegisterCart＋実Recovery試験で確認した。結果不明は有効な未解決購入補助記録で通常編集と区別し、新たなcart.stateを追加していない。PENDINGはmember_id=null・指定候補pending_member_id・参考額フラグtrueとして、API表示上の会員待ちを模擬している。

TC-20の実Chrome故障・複数購入記録と遅着確認、TC-24の実DBにおける応答断／同一再送／別ID拒否／操作GET／参照切替、TC-28の6状態での実セッション失効・元担当者／誤認証／別担当者・再読込・Cookie逆順到着は、今回の自動回帰で完了扱いにしない。既存の実機／実DB結果との照合と、残るMac実機確認が必要。iPhone・カメラは今回実施していない。

戻す場合は今回追加した回帰・専用harness・本結果票だけが対象。売上、保存領域、既存成果物の削除は不要。
