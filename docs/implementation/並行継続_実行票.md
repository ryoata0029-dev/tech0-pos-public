## 今回の固定対象

- profile `parallel-next`、container `tech0-pos-parallel-next-mysql`、volume `tech0-pos-parallel-next-mysql-data`。私有領域 `.parallel-next-local/` はGit除外、公開証跡は `evidence/parallel-next/`。旧環境・Cookie・期限は再利用しない。新規対象の不存在を確認しfresh setupする。
- loopback MySQL3307 / HTTPS8443・8444、digest固定MySQL8.4.11、TLS必須。Cloudflareの新しい一時URLは起動後に記録する。証明書の端末信頼設定は変更しない。
- iPhone画面試験は `parallel-next` の `pos_validation`。Mac画面試験は別固定profile `parallel-mac-next` / container `tech0-pos-parallel-mac-next-mysql` / volume `tech0-pos-parallel-mac-next-mysql-data` / 私有 `.parallel-mac-next-local/` / 証跡 `evidence/parallel-mac-next/` の新規環境を用い、MySQL3317 / HTTPS8453・8454へ固定分離する。各環境の1レジを正規初回startし、担当者Cookie/DB/公開origin/TLSを独立させる。端末間Cookie移植や同じ取引の引継ぎは行わない。buildは検証済み同じ成果物を読取利用、サーバー・build・DB・GUIは主担当が管理する。
- API/DBの追加実検証は同じ隔離containerの新規専用schema `pos_api_validation` に分離する。実FastAPIのASGI経路と実MySQL接続で行い、HTTPS/実ブラウザの合格には数えない。電話カートへデータ変更しない。
- サブエージェントAは実DBスクリプト/結果、Bはphone作業票/独立結果、CはMac手順/独立レビュー。共有toolsは主担当が管理し、今回のMac固定profile・port分離だけはCへ所有範囲を明示して編集委任した。環境・DB・build・GUIの実行は主担当のみ。新しい本番依存は導入しない。
