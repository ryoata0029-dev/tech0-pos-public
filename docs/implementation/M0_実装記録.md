導入前にPyPI／npmの依存条件・ライセンス・配布物情報を取得し、公開パッケージ名・版だけをOSVへ照会。最終構成はPythonの本番＋開発48パッケージ、npmのoptionalプラットフォーム依存を含む171パッケージ。照会時点の該当報告は0件。OS・ランタイム全体、未登録脆弱性、将来の安全性を保証しない。

- [Pythonの確認根拠](evidence/m0/python-dependencies.json)：解決した版・Requires-Python・依存・ライセンス・配布物SHA-256・OSV結果。
- [npmの確認根拠](evidence/m0/npm-dependencies.json)：ロック全体の版・ライセンス・integrity・OSV結果。
- [直接依存とNodeの候補根拠](evidence/m0/npm-candidates.json)：公式公開メタデータ・取得日時。
- [導入済みライセンス／NOTICEの所在とハッシュ](evidence/m0/license-files.json)。pwdlibのMIT、pathspecのMPL-2.0は配布物本文も確認した。

主要な本番直接依存はMIT／BSD系列。Next.jsのoptional画像依存にLGPL-3.0-or-laterのlibvips等、caniuse-liteにCC-BY-4.0を含む。開発用pathspecはMPL-2.0。ライセンス／NOTICEを保持し、配布方法を決める時に各配布物の条件を確認する。依存を「全てMIT」とは扱わない。今回のコードにライブラリ本文のコピーや改変は行っていない。

TypeScript 7はtypescript-eslintの対応範囲外だったため5.9.3へ固定。ESLint 9には保守終了警告があり10へ変更したが、`eslint-config-next`の間接依存に10非対応のものが残るため、公式Nextプラグイン・TypeScript規則を直接構成した。クリーン領域でstrict peer依存検査を通し、強制解決は使っていない。公式の[Next ESLintプラグイン設定](https://nextjs.org/docs/app/api-reference/config/eslint)を参照。

カメラライブラリは未使用のため未導入。採用時に保守・両端末での適合を再確認する。PythonロックはmacOS arm64／Python 3.13で解決・再導入済みで、Linuxの条件付き依存はAzure配置前に再確認する。Next.jsとFastAPIの選定系列は維持。参考：[Next.js導入](https://nextjs.org/docs/app/getting-started/installation)、[FastAPI版固定](https://fastapi.tiangolo.com/deployment/versions/)、[OpenAPI検証器](https://openapi-spec-validator.readthedocs.io/en/latest/)。
