2026-10-01。本人の「MAC側先に進めて」に基づく実行準備。**専用DB＋一時HTTPSは本人許可済み。今回はカメラ以外を実施。実機合格は未判定。**

実施後の条件別判定・未実施・環境停止は[結果票](Mac_業務復帰確認結果.md)。

対象：F08〜F25・T02、業務手順2〜6、TC-01〜03・06・10・18〜21・24・28、設計3〜5・7〜8。M3の業務一巡とM4のブラウザ側復帰をMac Chrome通常モードで確認する。[受入条件](../requirements/受入条件_現行.md)・[ケース詳細](../tests/テストケース.md)・[M4実DB証拠](M4_実DB障害競合検証.md)を併読する。M2の空カート復帰を商品ありの合格にしない。

## 実行対象

- 新規コンテナ `tech0-pos-mac-flow-mysql`、volume `tech0-pos-mac-flow-mysql-data`、DB `pos_validation`。既存M2／M3／M4は停止・保持し、移管・初期化しない。同名資源があれば上書きしない。
- 固定MySQL8.4・現行16表・架空担当者／会員／3商品。条件は103円×3・会員10%引き・税10%と107円商品2件・税8%。会員537円、非会員570円の確認用に準備する。
- Git除外 `.mac-flow-local/` に専用秘密値とlocalhost TLS。通常アプリは最小権限。端末の証明書信頼設定は変更しない。
- Mac Chromeが警告なしのHTTPSを使えるよう、既存Cloudflare検証CLIで今回のフロント画面・許可済みAPI中継だけを一時公開する案。FastAPI8444とMySQL3307はloopback。Cloudflareを経由するのは架空業務データ・この環境だけのログイン情報と認証／復帰Cookie・通常のアクセス情報。実顧客、既存環境の秘密値、ソース、DBを公開しない。
- Originは取得した一時HTTPS URLと完全一致させる。新規ログインと初回利用はブラウザ画面から開始し、サーバークライアントのCookieをブラウザへ移植しない。

## 順序・判定・記録

1. モデル・macOS・Chrome版を記録、同じ通常Chromeプロフィールを維持。ログイン・初回開始、手入力の会員／商品・数量・削除・計算・購入・次取引を画面とDBで照合。
2. 編集中の商品条件保持と、同一取引の再読込を確認。別タブで警告・古い操作の拒否・購入1件・継続先一致を確認する。
3. 会員待ち・保存受付中・応答不明・未保存・保存済み未終了・next移行後を、指定位置で制御できるケースから確認。制御不能なら未実施と記録し、画面だけを状態へ見せかけない。localStorageの破損等は今回のoriginの専用記録だけを扱い、他サイトの保存を変更しない。
4. Chrome完全終了／再起動は通常の再読込と別記録。終了直前に本人の他作業への影響を確認し、同じプロフィール・URLから復帰する。未送信の入力・選択行・カメラを復元せず、自動購入／新しいカートで回避しない。
5. カメラは許可範囲を確定して別実施。バーコードのみを映し、未登録・数量99後の継続、同コード抑止・再提示、閉じる／背景／再認証／購入時の停止を確認。認識をAPI反映成功とみなさない。

画面・DB・条件別の記録を `docs/implementation/evidence/mac-flow/` に保存し、秘密値・Cookie原値・担当者パスワード・不要なプロフィール情報を残さない。ログイン情報保存のブラウザ確認は保存せず閉じる。全34TC・両端末・Azureの合格へ拡張しない。

## 終了と残作業

今回の一時トンネル・HTTPS両アプリ・専用MySQLだけを停止し、公開URL閉鎖・3307/8443/8444非待受を確認。DBvolume・証跡を保持。DROP、既存volume削除、証明書信頼設定変更、commit/push、Azureは対象外。iPhone確認とAzure性能／復元は別工程。戻す場合は今回の検証器・専用profile差分だけをレビューする。
